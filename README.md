# Angad Sharma — Personal Portfolio Website

This repository contains the source code for the personal portfolio website of **Angad Sharma**, Chief Officer (VLCC Operations), maritime compliance architect, and award-winning maritime photographer.

## Overview
A fast, lightweight, self-contained single-page portfolio built with modern HTML5, CSS3, and vanilla JavaScript.

### Core Sections
* **Hero Overview:** Professional headline, command credentials, and verified location in Delhi, India.
* **About:** 20 years of operational navigation aboard Very Large Crude Carriers (VLCCs), systems thinking, and oceanic perspective.
* **Award-Winning Maritime Photography:** Highlighting 1st and 2nd place wins in INTERTANKO’s Annual Tanker Event 2023 (*Beam of Sunrays* and *Sunrise*), alongside a curated exhibition of maritime phenomena and life at sea with an interactive lightbox.
* **Maritime Career:** 20-year continuous sea time trajectory (Wallem Group, Suntech Ship Management, Synergy Marine Group) and zero-incident safety record.
* **VaultCrew:** Overview of the digital crew compliance platform engineered for Indian RPSL manning agencies.
* **Credentials:** Statutory certifications including Certificate of Competency (First Mate FG) and B.Sc. Nautical Science.
* **Connect:** Direct email inquiry and custom navy-and-gold styled LinkedIn quick-connect QR code.

## Local Preview
Simply open `index.html` in any modern web browser (Safari, Chrome, Firefox, or Edge). No build steps, dependencies, or external servers are required.
